# VIVO — Employee App Prototype

A live, interactive web build of the **VIVO Digital Health Insurance** employee
mobile app, on the new brand identity. Runs entirely on **demo data** — no
backend, no real patient information.

**Live:** https://ayousry2122343.github.io/vivo-prototype/

## What to try
- On first load: brand splash → onboarding → sign-in. Any email + password
  signs in (demo).
- Toggle **light / dark** and **العربية / English** from the Account screen
  (bottom-right tab), or preset them with the URL:
  - `?theme=dark` · `?theme=light` · `?theme=system`
  - `?lang=ar` · `?lang=en`
  - e.g. `.../vivo-prototype/?lang=ar&theme=dark`
- Resize the window: phones get a bottom bar, tablets a side rail and two-column layouts.

## Notes
- Built with Flutter (web). Source lives in the private VIVO monorepo.
- Design system: brand colours, typography, logo kit and tokens are the same
  set the admin + companies dashboards will adopt.
